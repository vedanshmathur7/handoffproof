# Definition of done

A task is done only when all applicable items are true:

- Observable behavior exists.
- Acceptance tests cover important success and failure paths.
- Tests, linting, type checks, and build pass.
- Inputs and workspace boundaries are validated.
- Loading, empty, partial-coverage, and error behavior are handled.
- No secrets or private customer data were added.
- Contract docs match material implementation changes.
- `docs/STATUS.md` lists exact checks and exactly three next actions.
- No checklist item is marked complete based on assumption.
