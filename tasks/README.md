# Task execution rules

1. Read `AGENTS.md` and `docs/STATUS.md`.
2. Work only on the active task.
3. Execute unchecked steps top to bottom.
4. Run each acceptance command.
5. Check a box only after observing the expected result.
6. If blocked, record the exact blocker and leave the box unchecked.
7. When complete, point status to the next task and keep exactly three next actions.

One agent owns one task at a time. Parallel agents may work only on explicitly independent tasks and must not edit the same files.
