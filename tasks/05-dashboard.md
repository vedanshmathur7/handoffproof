# Task 05: Dashboard

## Goal

Let an interviewer complete the CSV workflow without API tools.

## Steps

- [ ] Add local demo workspace bootstrap.
- [ ] Build separate source and destination upload steps.
- [ ] Show file schema, accepted/rejected counts, and row errors.
- [ ] Build rule form from backend-returned fields.
- [ ] Explain identity, eligibility, required fields, waiting, and unknown simply.
- [ ] Start reconciliation and show truthful progress.
- [ ] Display summary counts and coverage prominently.
- [ ] Add exception filters for all categories.
- [ ] Show source evidence, candidates, differences, rule version, and timestamps.
- [ ] Add review notes without replacing machine reasons.
- [ ] Add results download.
- [ ] Handle loading, empty, partial, validation, server-error, and retry states.
- [ ] Test these behaviors.
- [ ] Run the entire workflow in a browser and record observed counts.

## Acceptance

- Fresh reviewer reaches results without code knowledge.
- Each exception is explainable from visible evidence.
- Partial coverage cannot look healthy.
