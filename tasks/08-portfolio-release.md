# Task 08: Portfolio release

## Goal

Give an interviewer an honest five-minute demonstration.

## Steps

- [ ] Choose deployment target and document its limits.
- [ ] Add reproducible production config and migrations.
- [ ] Deploy only synthetic data unless real-data authority exists.
- [ ] Verify health, migration, import, reconciliation, evidence, review, and export.
- [ ] Add a deterministic demo reset.
- [ ] Put verified setup and architecture in README.
- [ ] Add screenshots or walkthrough including an `unknown` case.
- [ ] Write the interview script: problem, example, architecture, hardest decision, tests, limitation, next step.
- [ ] Separate measured values from targets and demo values.
- [ ] Run from a fresh browser twice after clean reset.
- [ ] Record release URL, commit, date, checks, blockers, and next three actions.

## Acceptance

- Reviewer understands and sees value in five minutes.
- README has no invented claims.
- Deployed demo works twice from clean state.
